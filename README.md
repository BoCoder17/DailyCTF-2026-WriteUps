# 🏆 DailyCTF Write-ups

Этот репозиторий создан по итогам проведения соревнований **DailyCTF**. Здесь собраны подробные разборы (write-up'ы) и пошаговые решения на каждое задание с понятным объяснением логики поиска и анализа.

Сами оригинальные задания и анонсы ивентов публикуются в сообществе [Community DailyCTF](https://t.me/+sQe0pGRw9KdlNGI6).
Обязательно подписывайтесь, чтобы не пропускать новые турниры!

## 🗂 Структура папки с заданием

Каждое задание оформлено в отдельном файле разметки и сопровождается необходимыми материалами:
* `files/` — исходные файлы, бинарники и архивы, выданные к заданию.
* `photo/` — вспомогательные изображения и скриншоты для наглядности решений в write-up'ах.
* `writeup.md` — подробный разбор (write-up) с описанием шагов решения и флагом.
